# 蓝生万象 · 蜡染工坊

纯静态网页，可直接部署到 GitHub Pages，无需构建、后端或安装依赖。

## 上传与发布

1. 新建 GitHub 仓库（GitHub Free 请使用公开仓库）。
2. 将本目录里的文件和 assets 文件夹上传到仓库根目录。仓库首页应直接看见 index.html。
3. 提交文件到 main 分支。
4. 打开仓库 Settings → Pages。
5. Source 选择 Deploy from a branch；分支选择 main，目录选择 /(root)，点击 Save。
6. 等待部署完成，在 Pages 页面点击 Visit site。

项目站点地址通常为 https://你的用户名.github.io/仓库名/ 。所有运行资源使用相对路径，可用于仓库子路径。
